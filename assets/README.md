# Lokale Tokenbilder

Lege PNG-, JPG- oder WebP-Dateien bis 2 MB hier ab. Die CSV-Spalte `image_path` kann z. B. `assets/dein-token.png` enthalten. Absolute Pfade innerhalb dieses Ordners funktionieren ebenfalls; andere Verzeichnisse sind nicht freigegeben. Auch Symlinks dürfen nicht aus diesem Ordner herausführen.

Die CSV-Vorlage enthält beispielhafte Dateinamen. Die Bilddateien selbst sind nicht enthalten; ersetze die Pfade durch deine Dateien. Fehlende Bilder verhindern den CSV-Import nicht. Beim Laden eines Eintrags wird ein lesbarer Fehler angezeigt.

Lokale Bilder werden nur als Vorschau angezeigt. Sie werden nicht veröffentlicht. Eine vorhandene oder die Standard-Metadata-URL wird durch das lokale Bild nicht verändert. Für ein eigenes On-Chain-Bild musst du eine öffentlich gehostete Metadata-JSON mit passendem Bildverweis angeben.
